# macOS design specs

Canvas: 760×680 pt default window (`LetsLapseApp.defaultSize`); capture presents as a ≥960×720 sheet.

🟡 **All files planned — none drawn yet.** macOS shares the SwiftUI screens with iOS but differs structurally: the floating pill tab bar replaces native tabs (reselect-to-pop), the version flow lives *inside* the Create tab rather than as a full-screen overlay, capture is a sheet, and Settings adds a Camera access card. When macOS UI work happens, files land here following [../README.md](../README.md).
